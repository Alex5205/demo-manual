# demo-manual

Простой CLI-калькулятор и мини-HTTP-сервис на Java. Проект реализован на чистом JDK без сторонних фреймворков (Spring, Hibernate и т.д.) и без систем сборки (Maven/Gradle).

Цель проекта: показать понимание базовой логики бэкенда, работы с HTTP и обработки ошибок на минималистичном стеке.

## Возможности

### CLI-версия (`Main`)
- Поддержка операций: `+`, `-`, `*`, `/`.
- Валидация входных аргументов.
- Обработка деления на ноль (без падения приложения).
- Запуск через `java -cp`.

### HTTP-версия (`HttpCalcServer`) — мини-бэкенд
- Встроенный HTTP-сервер на базе `com.sun.net.httpserver.HttpServer`.
- Приём POST-запросов с JSON-телом.
- Ручной парсинг JSON (без библиотек вроде Jackson/Gson) для демонстрации понимания формата.
- Возврат структурированного JSON-ответа.
- Обработка ошибок: неизвестный оператор, деление на ноль, неверный формат данных.

## HTTP‑версия (мини‑бэкенд)

Добавлен простой HTTP‑сервер на чистом Java (`com.sun.net.httpserver`) — без фреймворков и внешних зависимостей. Сервер принимает POST‑запросы с JSON, выполняет арифметические операции и возвращает структурированный JSON‑ответ.

**Запуск:**
```powershell
java -cp target\classes com.example.HttpCalcServer

## Почему это полезно для бэкенд‑разработки

- **Понимание «под капотом»:** работа с `HttpServer` и ручным парсингом JSON показывает, как устроены HTTP‑сервисы без абстракций фреймворков.  
- **Обработка ошибок:** проект корректно обрабатывает деление на ноль, неизвестные операции и неверный формат JSON.  
- **Лёгкий стек:** отсутствие зависимостей позволяет запускать проект на слабых машинах (например, с 2 ГБ ОЗУ).  
- **Готовность к расширению:** архитектура позволяет легко добавить логирование, валидацию диапазонов или метрики.
