# demo-manual

Простой калькулятор на Java в двух режимах:
1. **CLI** (командная строка) — для быстрых расчётов.
2. **HTTP** (мини-бэкенд) — принимает JSON-запросы, возвращает JSON-ответы.

Реализовано на чистом Java без сторонних библиотек и фреймворков. Проект оптимизирован для работы на ограниченных ресурсах (2 ГБ ОЗУ).

---

## Особенности

- Валидация входных данных.
- Обработка деления на ноль.
- Возврат структурированного JSON-ответа.
- Два режима работы в одном проекте.
- Сборка и запуск через стандартный JDK (без Maven/Gradle).

## Как запустить

### HTTP-режим (мини-бэкенд)

Запускает простой HTTP‑сервер на порту 8080. Принимает POST‑запросы с JSON‑телом, возвращает JSON‑ответ.

**Запуск сервера:**
```powershell
javac -d target\classes src\main\java\com\example\HttpCalcServer.java
java -cp target\classes com.example.HttpCalcServer



## Почему это хороший учебный проект

- **Два интерфейса в одном проекте:** CLI и HTTP.
- **Работа с HTTP «под капотом»:** `com.sun.net.httpserver`, обработка запросов, чтение тела, заголовки.
- **Ручной парсинг и сборка JSON** без сторонних библиотек — показывает понимание формата данных.
- **Обработка edge cases:** деление на ноль, неверные операции, пустой запрос.
- **Минимальный стек:** только JDK, без Maven/Gradle и тяжёлых фреймворков.
- **Оптимизация под ограниченные ресурсы:** проект стабильно работает на слабых машинах.
